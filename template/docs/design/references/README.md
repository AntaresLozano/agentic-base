# Referencias visuales

La IA "no tiene ojos" hasta que le das imágenes. Esta carpeta contiene capturas que puede leer.

## Qué guardar aquí

1. **Apps de referencia (fase 2):** 5-10 capturas de apps cuyo estilo te gusta. Nómbralas
   `ref-<app>-<pantalla>.png`.
2. **Prototipos elegidos:** cuando eliges una variante con `/ui-prototypes`, guarda su captura como
   `screen-<feature>-<pantalla>.png`. Es la referencia que usa el subagente `ui-verifier`.

## Índice

Añade una línea por imagen diciendo qué tomar de ella:

| Archivo                           | Qué tomar de ella                                          |
| --------------------------------- | ---------------------------------------------------------- |
| _ejemplo:_ `ref-things-today.png` | Jerarquía tipográfica y aire entre elementos. No el color. |
